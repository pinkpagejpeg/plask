# 🚀 Plask

**Plask** — это помощник в организации задач и целей.  
Планировщик помогает эффективно управлять рабочим и личным временем и достигать поставленных целей.

Простой и интуитивно понятный интерфейс позволяет быстро начать работу без сложного онбординга.


## ✨ Возможности

- 📋 Создание и управление задачами  
- 🎯 Постановка и отслеживание целей  
- ⚡ Быстрый и удобный интерфейс  
- 🔄 Клиент–серверная архитектура  


## 🛠 Технологический стек

### Backend

- Express  


## 🚀 Запуск проекта в режиме разработки

### 1. Запуск сервера

Перейдите в директорию `server` и запустите сервер с помощью `npm run start` (не забудьте установить зависимости):

```bash
cd server
npm install
npm run start
```

### 2. Запуск клиента

Перейдите в директорию `client` и запустите клиент с помощью `npm run dev` (не забудьте установить зависимости):

```bash
cd client
npm install
npm run dev
```

### 3. Открытие приложения

После запуска клиента откройте ссылку, указанную в терминале  
(по-умолчанию `http://localhost:5173`).
